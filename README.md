# easy-remote

Mac 到 Windows 的安全远程访问笔记，重点介绍 WireGuard 隧道与远程桌面（RDP）的组合。

## 核心方案

Mac 作为 WireGuard 客户端连接到受控的云端中继，再通过私有隧道访问 Windows。RDP 只在 WireGuard 网段内开放，不直接暴露到公网。

## 文档

- [Mac 连接 Windows 指南](docs/mac-to-windows.md)：客户端配置、连接步骤、安全检查和排障。

## 安全边界

- 文档中的地址和账号均为示例或占位符；部署前替换成自己获批的配置。
- WireGuard 私钥、实际服务器地址、用户名和口令不得提交到仓库。
- 只开放获批的 WireGuard UDP 端口；不要把 RDP（3389）或 VNC（5900）暴露到公网。
- Windows 侧启用 NLA，并把 RDP 防火墙规则限制在 VPN 网段。

## 资料整理说明

内容整理自本机的 Mac 客户端使用说明、远程访问运行手册、架构与验收记录，以及 RDP 输入体验笔记。已移除真实公网地址、机器名、账号和密钥信息；没有复制私钥、实际配置、备份文件或安装包。
